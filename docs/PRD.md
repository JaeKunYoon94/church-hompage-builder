# 교회 홈페이지 빌더 PRD

작성일: 2026-10-18

## 개요

컴퓨터에 익숙하지 않은 교회 담당자도 30분 안에 홈페이지를 만들고, 매주 설교·주보 업데이트를 5분 안에 끝내게 하는 교회 전용 홈페이지 빌더를 만든다.

**문제**

- 작은 교회는 홈페이지를 외주로 만든 뒤 수정할 사람이 없어 몇 달씩 방치된다.
- 범용 빌더(Wix, 아임웹 등)에는 설교·주보·예배 시간 같은 교회 콘텐츠 구조가 없어 매번 직접 꾸며야 한다.
- 담당 간사·봉사자가 자주 바뀌어 사용법이 인수인계되지 않는다.

**해결 방향**

- 교회에 필요한 섹션(예배 안내, 최근 설교, 주보, 오시는 길 등)을 완성된 블록으로 제공한다.
- 관리자는 블록을 드래그앤드롭으로 추가하고 순서를 바꿔 페이지를 구성한다.
- 설교·주보·공지는 정해진 입력 폼에 넣기만 하면 해당 블록에 자동으로 반영된다. 레이아웃과 콘텐츠를 분리해, 매주 하는 일은 폼 입력뿐이다.

**목표 (출시 후 3개월)**

- 가입 후 첫 발행까지 중앙값 30분 이하
- 가입 교회의 50% 이상이 매주 콘텐츠를 업데이트

## 대상 사용자

핵심 사용자는 매주 사이트를 고치는 교회 관리자이며, 모든 화면은 40\~60대 비전공자가 설명서 없이 쓸 수 있어야 한다.

| 사용자 | 누구 | 하는 일 | 핵심 니즈 |
| --- | --- | --- | --- |
| 교회 관리자 (주 사용자) | 행정 간사, 부목사, 미디어팀 봉사자 | 사이트 개설, 매주 설교·주보·공지 업로드 | 쉽고 적은 버튼, 실수해도 되돌리기 |
| 사이트 소유자 | 담임목사 또는 교회 대표 | 관리자 초대·권한 부여, 최종 확인 | 휴대폰으로 미리보기, 담당자가 바뀌어도 권한 이전 |
| 방문자·성도 | 새신자, 이사 온 가정, 기존 성도 | 예배 시간·위치 확인, 설교 다시 보기, 주보 보기 | 휴대폰에서 첫 화면에 예배 시간·오시는 길 |
| 플랫폼 운영자 | 서비스 운영팀 | 템플릿·블록 관리, 고객 지원 | 교회별 사이트 상태 확인, 대리 로그인 없이 문제 재현 |

## 범위

MVP는 여러 교회가 가입해 각자 사이트를 무료로 만드는 서비스(SaaS)이며, ‘만들기 + 매주 업데이트’만 다룬다. 교인 관리·결제는 다루지 않는다.

**MVP 포함**

- 교회 가입과 사이트 생성 (교회명, 주소, 예배 시간만 입력하면 초안 자동 완성)
- 시작 템플릿 3종
- 드래그앤드롭 페이지 편집기와 교회 특화 블록
- 콘텐츠 관리: 설교, 주보, 공지, 일정, 앨범, 섬기는 분들
- 관리자 역할 3종(소유자·관리자·편집자)
- 기본 주소(`교회이름.서비스도메인`)와 보유 도메인 연결
- **보안·개인정보 보호 기본 탑재**: 가입 약관·개인정보 동의, 개인정보처리방침 자동 생성, 폼 수집 동의, HTTPS·2단계 인증. 끄거나 빼는 옵션 없음

**MVP 제외 (추후 검토)**

- 온라인 헌금·결제
- 교인 명부, 출석, 심방 관리
- 성도 회원 로그인, 게시판 댓글
- 예배 라이브 자체 송출 (유튜브 링크 삽입으로 대체)
- 블록 안 요소의 픽셀 단위 자유 배치 (블록 순서 변경만 제공)
- 다국어 사이트, 전용 모바일 앱

## 드래그앤드롭 페이지 편집기

관리자는 블록을 끌어 놓아 페이지 구성과 순서를 바꾸고, ‘발행’을 누르기 전까지 공개 사이트는 바뀌지 않는다. 화면은 왼쪽 블록 목록, 가운데 페이지 미리보기, 오른쪽 설정 패널의 3단 구성이다.

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| E-01 | 블록 목록에서 페이지로 끌어 놓아 블록 추가. 블록 사이 ‘+’ 버튼으로도 추가 가능 | P0 출시 필수 |
| E-02 | 블록을 위아래로 끌어 순서 변경. 놓일 위치를 가이드 선으로 표시 | P0 출시 필수 |
| E-03 | 드래그가 어려운 사용자를 위해 블록마다 ↑/↓ 버튼과 키보드 이동 제공 | P0 출시 필수 |
| E-04 | 블록을 누르면 오른쪽 패널에서 문구·사진·배경색 수정. 문구는 미리보기에서 바로 고침 | P0 출시 필수 |
| E-05 | 블록 숨기기(삭제 없이 비공개), 삭제. 같은 종류 블록은 페이지당 하나만 둘 수 있고, 이미 있으면 추가 대신 그 블록을 선택하거나 놓은 자리로 옮김 | P0 출시 필수 |
| E-06 | 변경 즉시 초안 자동 저장, 실행 취소·다시 실행 | P0 출시 필수 |
| E-07 | PC·모바일 미리보기 전환 | P0 출시 필수 |
| E-08 | ‘발행’으로 초안 공개, 직전 발행본으로 한 번에 되돌리기 | P0 출시 필수 |
| E-09 | 페이지 추가·삭제, 상단 메뉴 순서를 드래그로 변경 | P0 출시 필수 |
| E-10 | 두 명이 같은 페이지를 동시에 열면 경고 표시 | P1 출시 직후 |
| E-11 | 휴대폰에서 터치로 블록 순서 변경 | P1 출시 직후 |
| E-12 | 발행 예약 (예: 토요일 밤 10시 공개) | P1 출시 직후 |
| E-13 | 내가 만든 블록 조합을 ‘내 블록’으로 저장해 재사용 | P2 검토 |

## 섹션 블록 라이브러리

블록은 문구를 직접 넣는 ‘직접 입력형’과 콘텐츠를 불러오는 ‘자동형’ 두 가지다. 자동형 덕분에 매주 페이지 편집기를 열 필요가 없다. 블록마다 디자인 변형 2\~3개(예: 사진 왼쪽/오른쪽)를 고를 수 있다.

| 블록 | 보여주는 내용 | 내용 출처 | 우선순위 |
| --- | --- | --- | --- |
| 대표 배너 | 교회 사진, 표어, 버튼. 여러 장이면 슬라이드로 넘어감 | 직접 입력 | P0 출시 필수 |
| 예배 안내 | 예배명·요일·시간·장소 | 사이트 설정 (자동) | P0 출시 필수 |
| 최근 설교 | 최신 설교 영상 1편 + 목록 3편 | 설교 (자동) | P0 출시 필수 |
| 주보 | 이번 주 주보 보기·내려받기 | 주보 (자동) | P0 출시 필수 |
| 공지사항 | 최근 공지 5개 | 공지 (자동) | P0 출시 필수 |
| 오시는 길 | 지도, 주소, 주차·대중교통 안내, 티맵·네이버지도·카카오맵 바로가기(주소로 자동 연결), 교회명·주소 카드와 주소 복사 버튼 | 사이트 설정 (자동) | P0 출시 필수 |
| 교회 소개 | 사진과 글 (비전, 연혁) | 직접 입력 | P0 출시 필수 |
| 섬기는 분들 | 목회자·교역자 사진과 직분 | 섬기는 분들 (자동) | P0 출시 필수 |
| 글·사진 | 자유 문단과 사진 | 직접 입력 | P0 출시 필수 |
| 문의·새가족 등록 폼 | 이름·연락처·문의 입력. 개인정보 수집 동의 체크박스가 자동으로 붙고 버튼만으로는 뺄 수 없음 | 폼 응답 (관리자에게 알림) | P0 출시 필수 |
| 교회 일정 | 이번 달 행사 목록 | 일정 (자동) | P1 출시 직후 |
| 사진 앨범 | 최근 앨범 썸네일 | 앨범 (자동) | P1 출시 직후 |
| 새가족 안내 | 첫 방문 안내, 전화·카카오톡 채널 버튼 | 직접 입력 | P1 출시 직후 |
| 유튜브 라이브 | 예배 생중계 영상 | 유튜브 채널 주소 | P1 출시 직후 |
| 헌금 계좌 안내 | 계좌번호와 복사 버튼 | 직접 입력 | P1 출시 직후 |

## 관리자 콘텐츠 관리

매주 반복하는 일은 모두 정해진 입력 폼으로 처리하고, 저장하면 해당 블록에 바로 반영된다. 콘텐츠 관리는 종류마다 별도 메뉴(대표 배너·설교·주보·공지사항·섬기는 분들)로 나뉘고, 대표 배너는 입력하는 대로 실제 모습을 미리 보여 준다. 관리자 첫 화면은 ‘이번 주 할 일’(설교·주보 미등록 알림)을 보여준다.

| 콘텐츠 | 입력 항목 | 화면 반영 | 우선순위 |
| --- | --- | --- | --- |
| 대표 배너 | 여러 장 등록(순서 변경·삭제, 홈페이지에서 6초마다 자동 넘김), 제목(선택), 부제, 버튼 문구와 이동할 구역, 배경 사진(끌어다 놓기), 글자 위치, 사진 어둡게. 입력 중 실시간 미리보기 | 대표 배너 블록 | P0 출시 필수 |
| 설교 | 유튜브 퍼가기 코드(iframe) 또는 링크(붙여넣으면 제목·썸네일 자동, 코드는 영상 ID만 저장하고 붙여넣은 HTML은 쓰지 않음), 제목, 본문 말씀, 설교자, 날짜. 등록 후 수정 가능 | 최근 설교 블록(썸네일을 누르면 영상 재생), 설교 목록 페이지 | P0 출시 필수 |
| 주보 | 날짜, PDF 또는 사진 | 주보 블록(표지 미리보기, 누르면 전체 화면으로 넘겨 보기), 주보 목록 페이지 | P0 출시 필수 |
| 공지 | 제목, 본문, 상단 고정, 게시 기간 | 공지사항 블록, 공지 목록 | P0 출시 필수 |
| 섬기는 분들 | 이름, 직분, 사진, 소개, 표시 순서 | 섬기는 분들 블록 | P0 출시 필수 |
| 사이트 설정 | 교회명, 아이콘(로고), 대표 색상(기본 4가지 + 직접 고르기, 글자 대비 경고), 주소, 예배 시간표, 연락처, SNS 링크 | 예배 안내·오시는 길 블록, 머리말·꼬리말 | P0 출시 필수 |
| 폼 응답 | 응답 목록, 처리 완료 표시, 엑셀 내려받기 (다운로드 기록 남김) | 관리자 화면 전용 | P0 출시 필수 |
| 일정 | 행사명, 날짜·시간, 장소, 반복 | 교회 일정 블록 | P1 출시 직후 |
| 앨범 | 앨범명, 사진 여러 장 일괄 업로드(자동 압축) | 사진 앨범 블록, 앨범 페이지 | P1 출시 직후 |

**공통 규칙**

- 모든 콘텐츠는 공개/비공개 전환, 예약 게시가 가능하고, 삭제하면 30일간 휴지통에 보관한다.
- 설교·주보·공지는 휴대폰 관리자 화면에서도 등록할 수 있다.

**관리자 권한**

| 역할 | 할 수 있는 일 | 할 수 없는 일 |
| --- | --- | --- |
| 소유자 | 모든 기능, 관리자 초대·해제, 소유권 이전, 도메인, 사이트 삭제 | — |
| 관리자 | 페이지 편집·발행, 모든 콘텐츠, 폼 응답 열람 | 관리자 초대, 사이트 삭제 |
| 편집자 | 설교·주보·공지·일정·앨범 입력 | 페이지 편집·발행, 폼 응답(개인정보) 열람 |

## 주요 사용자 흐름

> (그림: 페이지 구성과 콘텐츠가 홈페이지에 반영되는 두 경로 — 원본 PRD 문서에서 볼 수 있어요)

페이지 구성은 발행해야 바뀌어 실수가 바로 노출되지 않고, 매주 콘텐츠는 저장만으로 반영돼 편집기를 열 필요가 없다.

**처음 개설 (목표 30분)**

1. 카카오·구글 계정 또는 이메일로 가입, 약관·개인정보 동의
2. 교회명, 주소, 예배 시간 입력 → 서브도메인 자동 제안
3. 템플릿 3종 중 선택 → 입력값이 채워진 초안 생성
4. 편집기에서 블록 순서·문구 수정, 개인정보 보호책임자 입력(처리방침 자동 생성)
5. 모바일 미리보기 확인 후 발행

**매주 업데이트 (목표 5분)**

1. 휴대폰 또는 PC로 로그인 → 첫 화면 ‘이번 주 할 일’
2. 설교: 유튜브 링크 붙여넣기 → 제목·썸네일 자동 → 본문 말씀·설교자 확인 후 저장
3. 주보: PDF 또는 사진 업로드 후 저장
4. 공개 홈페이지의 최근 설교·주보 블록에 즉시 반영 (발행 불필요)

## 보안 및 개인정보 (기본 탑재)

보안·개인정보 기능은 모든 교회 사이트에 기본으로 켜져 있고 관리자가 끌 수 없다. 새가족 등록·기도 제목처럼 신앙을 드러내는 정보는 민감정보로 볼 수 있어 일반 동의와 분리해 받는다. 근거 조항은 개인정보 보호법 기준이며 출시 전 법률 검토를 받는다.

| ID | 요구사항 | 근거 | 우선순위 |

## 기술 구성 제안

서버를 직접 운영하지 않는 관리형 서비스 조합으로, 3\~4명이 12주 안에 MVP를 만들 수 있게 한다. 데이터는 모두 서울 리전에 두어 개인정보 국외 이전 문제를 피한다.

| 영역 | 제안 | 이유 |
| --- | --- | --- |
| 공개 사이트·관리자 화면 | Next.js (React) | 공개 페이지 정적 생성과 관리자 화면을 한 코드베이스로 |
| 드래그앤드롭 | dnd-kit | 키보드·터치 지원(E-03, E-11), 세로 목록 정렬에 충분 |
| DB·로그인·파일 | Supabase (Postgres, Auth, Storage), 서울 리전 | 행 단위 접근 제어(RLS)로 교회별 격리(S-11), 카카오 로그인 |
| 호스팅·도메인 | Vercel | 교회별 서브도메인·보유 도메인 연결, HTTPS 자동(S-10) |
| 지도 | 카카오맵 또는 네이버 지도 API | 국내 주소 정확도 |
| 알림 | 이메일 발송 서비스, 카카오 알림톡(P1) | 폼 응답·이번 주 할 일 알림 |

**데이터 모델**

페이지의 블록은 JSON 배열 하나로 저장하고, 배열 순서가 곳 화면 순서다. 드래그로 순서를 바꾸면 배열을 재정렬해 초안에 저장하고, 발행하면 초안을 발행본으로 복사하며 이력에 한 줄을 남긴다.

| 테이블 | 주요 필드 | 비고 |
| --- | --- | --- |
| churches | 이름, 서브도메인, 보유 도메인, 사이트 설정(JSON) | 교회 1곳 = 테넌트 1개 |
| members | church\_id, user\_id, 역할 | 소유자·관리자·편집자 |
| pages | church\_id, 경로, 메뉴 순서, draft\_blocks(JSON), published\_blocks(JSON) | 블록 순서 = 배열 순서 |
| page\_versions | page\_id, blocks(JSON), 발행 시각, 발행자 | 되돌리기(E-08) |
| sermons, bulletins, notices, events, albums, staff | church\_id, 콘텐츠 필드, 공개 여부, 게시 시각, 삭제 시각 | 자동형 블록이 조회 |
| form\_responses | church\_id, 암호화된 응답, 동의 내역, 파기 예정일 | S-02, S-08, S-14 |
| consent\_logs, access\_logs | 누가·언제·어느 버전에 동의 / 개인정보 열람·다운로드 기록 | S-01, S-14 |

## 성공 지표

핵심 지표는 ‘쉬움’(첫 발행까지 시간)과 ‘지속’(매주 업데이트 비율) 두 가지다. 목표는 정식 출시 3개월 시점 기준이다.

| 지표 | 목표 | 측정 방법 |
| --- | --- | --- |
| 가입 → 첫 발행 시간 (중앙값) | 30분 이하 | 가입 시각과 첫 발행 시각 차이 |
| 7일 내 발행한 교회 비율 | 60% 이상 | 가입 코호트별 발행 여부 |
| 매주 콘텐츠를 올리는 교회 비율 | 50% 이상 | 주간 설교·주보·공지 등록 교회 수 ÷ 발행 교회 수 |
| 설교 등록 소요 시간 (중앙값) | 3분 이하 | 폼 열기부터 저장까지 |
| 전체 문의 중 사용법 문의 비율 | 20% 이하 | 고객지원 티켓 분류 |
| 개인정보 사고·유출 | 0건 | 보안 사고 대장 |
