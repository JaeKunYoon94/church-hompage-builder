# church-hompage-builder
교회 홈페이지 빌더

관리자가 코드 없이 교회 홈페이지를 만들고, 블록을 끌어다 놓아 배치 순서를 바꾸는 편집기 시안입니다.

## 실행

React + TypeScript + shadcn/ui(Tailwind CSS) 프로젝트입니다. Node.js가 필요합니다.

```
npm install
npm run dev        # 개발 서버 (시작 화면 /, 편집기 /editor.html)
npm run build      # 타입 검사 + dist/ 빌드
```

유튜브 정보·썸네일, 글꼴, PDF 미리보기는 인터넷 연결이 필요합니다.
`legacy/`에는 React로 옮기기 전의 단일 파일 시안(`index.html`, `main.html`)이 그대로 남아 있습니다. 브라우저로 바로 열 수 있고, 더 이상 쓰지 않으면 지워도 됩니다.

## 주요 기능

- **페이지 편집:** 블록 추가·삭제·숨기기, 드래그앤드롭과 ↑/↓로 순서 변경, PC·휴대폰 미리보기, 초안 자동 저장, 발행·되돌리기
- **콘텐츠 관리 (저장 즉시 반영):** 대표 배너(여러 장 슬라이드), 설교(유튜브 퍼가기 코드·링크), 주보(PDF 미리보기, 지난 주보), 공지사항, 섬기는 분들
- **사이트 설정:** 교회 이름·아이콘, 대표 색상(직접 고르기, 글자 대비 경고), 예배 시간표, 오시는 길(티맵·네이버지도·카카오맵 바로가기, 주소 복사), 개인정보 보호책임자
- **보안·개인정보:** 개인정보처리방침·이용약관 자동 생성, 문의 폼 수집 동의, 입력 내용 이스케이프 처리

## 시안의 한계

- 데이터는 그 브라우저의 저장 공간(localStorage)에만 저장됩니다. 서버·로그인은 없습니다.
- 지도 앱 아이콘은 각 회사 색으로 단순하게 그린 것입니다. 출시 전에 공식 로고로 바꿔야 합니다.
- 개인정보처리방침·이용약관은 기본 문안이므로 사용 전 법률 검토가 필요합니다.
